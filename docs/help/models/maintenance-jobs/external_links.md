# Регламентное обслуживание → Доп. связи

JSON-структура с произвольными машиночитаемыми данными регламентной операции.
При записи новые узлы объединяются со старыми (перезаписывается только то, 
что указано; удаление узла - запись пустого значения в соответствующий узел JSON).

Может удобно использоваться внешними интеграционными скриптами.

Продукт не навязывает состав ключей — организация
договаривается о своей схеме и строит на ней собственную автоматизацию.

## Пример использования

Пример формализованного описания процедуры резервного копирования

```json
{
  "backup": {
    "mechanism": "file",
    "source": "F:\\FileBackups\\MSSQL\\TCDB\\full\\ReportDB",
    "type": "file",
    "excludeExtensions": ["log", "tmp"]
  }
}
```

- `mechanism` - механизм резервного копирования:
  - `veeam-vm` - задание Veeam, бэкап ВМ целиком;
  - `file` - файловая резервная копия на диске (выгрузка БД, файлы сайта);
  - `tape` - задание переноса файловых бэкапов на ленту;
- `source` - путь к данным этой работы: для `file` - папка конкретного
  бэкапа, для `tape` - корневая папка всех файловых бэкапов;
- `type` - `file` (в источнике отдельные файлы-копии) или `folder`
  (копией является папка целиком);
- `excludeExtensions` - игнорируемые расширения.
