# VLAN

VLAN относится к конкретному L2-домену. Запись без L2-домена резервирует номер
для одинакового назначения во всех доменах, включая будущие площадки.

## Список

Название и пояснение локального VLAN берутся из его собственных полей.
Если поле пустое, используется значение глобального резерва с таким же номером.
Поиск и сортировка учитывают эти унаследованные значения.

## Добавление

Можно создать отдельный VLAN или включительный диапазон, например `100-110`.
Допустимы номера **1–4094**. Номера 1002–1005 разрешены в справочнике:
ограничения на их использование зависят от оборудования.

Номер должен быть уникальным внутри L2-домена. Для глобальных резервов
также допускается только одна запись на номер. Резерв не мешает создать
локальные VLAN с этим номером в разных доменах.

Весь диапазон проверяется до создания и сохраняется одной транзакцией.
При конфликте или ошибке сохранения частично созданный диапазон не остаётся.
Макрос `{VLAN}` в явно введённом названии заменяется номером каждой записи.

## Редактирование

Пустой L2-домен означает **«Резервирование VLAN»**.
Для локального VLAN плейсхолдеры названия и пояснения показывают значения резерва.
Оставьте поля пустыми для наследования либо введите собственные значения.

При изменении номера или домена плейсхолдеры обновляются после проверки формы.
У резерва нет родителя. Изменение его названия или пояснения отражается у локальных
VLAN с пустыми соответствующими полями. При удалении резерва наследуемое значение
исчезнет, собственные значения локальных VLAN сохранятся.

У VLAN с привязанными L3-сетями нельзя очистить L2-домен.

## Просмотр

Карточка и подсказки показывают вычисленные название и пояснение.
Глобальный резерв отмечен как резервирование для всех L2-доменов.

Чтобы использовать резерв в сети, сначала создайте локальный VLAN из
[карточки L2-домена](net-domains.md). Сеть связывается с локальным VLAN,
поэтому её L2-домен остаётся однозначным.
