# L2-домены

L2-домен группирует локальные VLAN площадки. Одинаковые номера VLAN
могут использоваться в разных доменах независимо.

## Просмотр

Грид VLAN по умолчанию показывает занятые номера — записи, созданные в этом домене.
Вариант «Занятые + резервы» добавляет к локальным VLAN глобальные резервы без локальной записи.
Фильтр колонки «Статус» также позволяет показать все номера либо только свободные,
включая глобальные резервы. Доступен общий поиск VLAN по номеру или диапазону, названию, пояснению и сетям.
В текстовых фильтрах несколько вариантов можно разделять символом `|`.
Таблица использует общие настройки колонок, ширины и размера страницы, а также экспорт.

- **Занят** — локальный VLAN; название и номер открывают его карточку.
- **Зарезервирован** — локального VLAN ещё нет, но есть глобальный резерв.
  Название и пояснение резерва показаны приглушённым цветом.
- **Свободен** — нет ни локального VLAN, ни глобального резерва.

Нажатие на название или номер свободной строки открывает создание VLAN
с выбранным номером в текущем домене. Для резерва название и пояснение появляются
как плейсхолдеры: можно сразу сохранить, оставив эти поля пустыми.

Один номер занимает одну строку. Если локальный VLAN уже создан, он имеет
приоритет над резервом. VLAN других доменов не занимают номера текущего.
Глобальные резервы видны и в новых доменах без автоматического создания записей.
