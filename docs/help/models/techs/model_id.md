# Оборудование → Модель оборудования

Нужно выбрать нужную [модель оборудования](../tech-models.md) из [списка](#doc-select:.field-techs-model_id). (Модели оборудования должны быть введены заранее — если нужной модели нет, переходим к задаче [добавление модели](../tech-models.md#добавление)).

В зависимости от выбранной модели оборудования поле **["Примечание"](#doc-select:.field-techs-comment)** может поменяться на другое (если у этого типа оборудования выставлена [замена комментария](../tech-types.md#attr-comment_name)).

- Для телефонов — номер телефона
- Для принтеров/МФУ — сетевой путь

Или может появиться поле [спецификация](specs.md), если у выбранной [модели оборудования](../tech-models.md) выставлен флажок [индив. спеки](../tech-models.md#attr-individual_specs)

- Например для каких-то серверных платформ, или офисных ПК с гибкой конфигурацией.
