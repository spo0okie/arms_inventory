# Типы лицензий

**Тип лицензии** — это полное/исчерпывающее описание лицензии в плане «как она работает».

Он состоит по сути из комбинации:

- [схемы лицензирования](lic-types.md)
- списка [ПО](soft.md), покрываемого этим типом лицензии

Что это значит? Проще всего объяснить на примере: есть лицензии на Windows 10 Pro, но они бывают разных типов. Например:

Лицензии **Windows 10 Pro OEM** лицензируют:

- Windows 10 Pro
- Windows 8.1 Professional (до тех пор, пока она поддерживается MS)
- Windows 7 Professional (до тех пор, пока она поддерживается MS)

### Источник (OEM)

[Лиц. соглашение](https://www.microsoft.com/en-us/Useterms/OEM/Windows/10/UseTerms_OEM_Windows_10_Russian.htm), пункт 7
*(способ активации даунгрейд-установок в соглашении не описан; на практике это решалось через линию поддержки Microsoft — код от более высокой версии обменивался на код для более низкой)*

По схеме лицензирования **OEM**: лицензия на ПО закрепляется за физическим ПК, с которым была приобретена, и не может быть установлена на другой ПК.

Лицензии **Windows 10 Pro BOX** лицензируют:

- Windows 10 Pro

### Источник (BOX)

[Лиц. соглашение](https://www.microsoft.com/en-us/Useterms/Retail/Windows/10/UseTerms_Retail_Windows_10_Russian.htm), пункт 7
(условие *«Если вы приобрели устройство у изготовителя или установщика с профессиональной версией Windows, предустановленной на нём»* — на BOX-редакции не выполняется)

По схеме лицензирования **BOX**: лицензия на ПО закрепляется за физическим ПК, но может быть перенесена на другой ПК.

Т.е. лицензии на Windows 10 бывают разные, работают по-разному, и всё несколько сложнее, чем просто «лицензии на Windows 10». Поэтому надо разбираться, что конкретно за лицензии мы покупаем, и закупки лицензий разного типа группировать по типам отдельно.

## Список

Доступен через главное меню **Лицензии → Типы лицензий**. Колонки
«Закупок акт/всего» и «Лицензий исп/всего» сводят количество активных
и распределённых лицензий — расшифровка каждой в подсказке заголовка.

## Просмотр

Карточка типа лицензий собрана из блоков:

- **шапка** — название типа, комментарий, [сервис](services.md)
  сопровождения; список лицензируемого [ПО](soft.md) и файлы-вложения;
  ответственный и команда поддержки;
- **[Распределение](#doc-anchor:usage)** (правый край) — сводка
  закупленных и распределённых лицензий этого типа;
- вкладки:
  - **Закупки** — [закупки лицензий](lic-items.md) этого типа (кнопка
    «Добавить закупку»);
  - **Привязки к [пользователям](users.md)**, **Привязки к
    [ОС / ВМ](comps.md)**, **Привязки к [АРМ](techs.md)** —
    распределение лицензий типа по объектам.

Значения полей и колонок поясняют их собственные подсказки (иконка «?») —
здесь только состав карточки.

## Редактирование

- Заполняем [список лицензируемого ПО](#doc-select:.field-licgroups-soft_ids) (программные продукты берутся из [реестра ПО](soft.md))
- Выбираем [схему лицензирования](lic-types.md) ([поле](#doc-select:.field-licgroups-lic_types_id))
- Вносим [описание](#doc-select:.field-licgroups-descr) типа лицензий
- Если надо распределять свободные лицензии — заполняем списки [«АРМы, куда распределять лицензии»](#doc-select:.field-licgroups-arms_ids), [«ОС/ВМ, куда распределять лицензии»](#doc-select:.field-licgroups-comps_ids) и/или [«Пользователи, на которых распределять лицензии»](#doc-select:.field-licgroups-users_ids)
- Вносим [комментарии](#doc-select:.field-licgroups-comment), если осталось что-то важное, что не вошло в другие поля
