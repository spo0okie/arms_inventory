# MAC-адреса

Списки MAC-адресов сетевых интерфейсов — атрибуты `mac` у
[операционных систем](../models/comps.md#attr-mac) и
[оборудования](../models/techs.md#attr-mac). Базовые правила ввода и поиска показываются
подсказками прямо у поля; здесь — подробности устройства.

## Хранение и нормализация

- При сохранении каждый адрес нормализуется до 12 шестнадцатеричных
  символов: `00:11:22:33:44:55`, `00-11-22-33-44-55` и `001122334455` —
  сохранится в один и тот же адрес `001122334455`.
- Диапазон хранится как упрощенные «начало-конец» `001122334455-001122334499`;
  границы при сохранении  упорядочиваются автоматически 
  (можно ввести «с большего», система поправит).

Диапазоны удобны для оборудования, которому производитель выделяет
последовательный блок адресов (например, шасси с множеством интерфейсов).

## Поиск по адресу

Рядом с каждым адресом в интерфейсе есть иконка поиска — в её подсказке
выбор, где этот адрес искать:

- **среди оборудования** — обычный список оборудования с фильтром по MAC
  (ищет и по адресу самого железа, и по адресу привязанной к нему ОС);
- **среди операционных систем** — список ОС с тем же фильтром: другие
  установки ОС на то же железо (предшественники, потомки, параллельные
  системы);
- **на портах коммутаторов** — опрос сетевого оборудования через
  [интеграцию поиска MAC](../admin/integrations/providers.md); пункты
  появляются, только если она включена. Их два: по площадке, где стоит
  объект (она названа в пункте), и «то же по всем площадкам» — на случай,
  если технику перевезли. Результат открывается окном: коммутатор, VLAN и
  порт, а порты, связанные с другими коммутаторами, помечаются как
  транзитные; в заголовке окна написано, где искали. Коммутаторы, которые
  опросить не удалось, перечислены там же ссылками на свои карточки с
  причиной («нет TCP-соединения», «не принял учётные данные»), чтобы было
  видно, где результат может быть неполным. Опрос идёт по клику,
  а не при открытии карточки — он занимает секунды и дёргает сетевое
  оборудование.

Первые два пункта — это обычные списки, поэтому там работают привычные
сортировка, колонки, отбор архивных и выгрузка.

Иконка появляется у одиночных адресов; у диапазонов (см. выше) её нет —
искать можно конкретный адрес. В списках иконки нет: там ту же задачу
решает фильтр колонки MAC.

## Особенности и ограничения

- Частичное совпадение (поиск по фрагменту адреса) работает только
  по одиночным адресам и границам диапазона.
  Попадание **внутрь диапазона** проверяется только для полного MAC-адреса: 
  фрагмент, который попал бы внутрь диапазона, не находится.
- Общий синтаксис поиска (`|` — ИЛИ, `&` — И, `!` — НЕ) применим
  к MAC-адресам как к обычным строкам.
