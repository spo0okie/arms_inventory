# Интеграция с DokuWiki

Подключение внешней DokuWiki, чтобы вести развернутые описания объектов в wiki и просматривать их прямо в интерфейсе инвентаризации.

Развернутые описания объектов удобно вести не в самой инвентаризации (форматирование ограничено Markdown), а во внешней wiki. Для подключения укажите в [config/params-local.php](../setup.md):

```php
return [
    'wikiUrl'=>'https://wiki.example.local/',
    'wikiUser'=>'inventory_doku_ro_user',
    'wikiPass'=>'inventory_doku_pass',
];
```

В самой DokuWiki в настройках в секции **"Параметры аутентификации"** необходимо

- включить API в параметре **"remote"**
- добавить добавленного выше пользователя в параметр **"remoteuser"**

### Как это работает

- Если в [списке ссылок](../../types/urls.md) объекта есть ссылка, начинающаяся с `wikiUrl`, то содержимое этой wiki-страницы будет загружено и показано прямо в карточке объекта (либо прямо в странице, либо будет добавлена вкладка).
- Страницы запрашиваются через JSON-RPC API DokuWiki (`lib/exe/jsonrpc.php`) под указанным пользователем - достаточно прав только на чтение.
- Тот же механизм используется для рендера полей с wiki-разметкой средствами DokuWiki.

### Кэширование и webhook

Загруженные из wiki страницы кэшируются на стороне инвентаризации. Чтобы кэш сбрасывался сразу при редактировании страницы в wiki, можно настроить на стороне DokuWiki (например, webhook-плагином) вызов URL:

```
https://inventory.example.local/web/wiki/invalidate-page?pageName=<идентификатор страницы>
```

Будет инвалидирована как сама страница, так и страницы, включающие ее через директиву `{{page>...}}`.

### Отчет по интервики-ссылкам

Страница **Настройки → Интервики-ссылки** (`/web/wiki/interwiki`, требует полномочия `admin`) собирает все [интервики-ссылки](https://www.dokuwiki.org/interwiki) вида `[[shortcut>страница]]`, которые встречаются в инвентаризации, и группирует их по shortcut и странице. По каждой ссылке видно, в каком объекте и в каком его поле она встретилась.

Что именно сканируется:

- все атрибуты всех сущностей, у которых в `textFields` включен рендер через `dokuwiki` (список просканированных полей раскрывается на самой странице);
- содержимое страниц wiki, включенных в такое поле директивами [плагина include](https://www.dokuwiki.org/plugin:include) - `{{page>...}}` и `{{section>...}}`. Обход рекурсивный (включение внутри включения), относительные пути (`{{page>.раздел}}`) разрешаются от страницы-источника. Такие ссылки в отчете помечены цепочкой включений, по которой они найдены.

Тексты включенных страниц запрашиваются из wiki при построении отчета, поэтому на больших деревьях включений страница строится небыстро. Управляющие параметры:

- `?includes=0` - не ходить в wiki, сканировать только сами поля инвентаризации;
- `?depth=N` - предельная глубина обхода включений (по умолчанию 3).

Страницы, которые не удалось получить (нет страницы, нет прав, wiki не настроена), перечисляются на странице отдельным предупреждением - ссылки из них в отчет не попали.

### Confluence

Помимо DokuWiki поддерживается подключение Confluence (через REST API): по аналогии задаются параметры **confluenceUrl**, **confluenceUser**, **confluencePass**, после чего ссылки на страницы Confluence в списках ссылок объектов также открываются во вкладке карточки объекта.
