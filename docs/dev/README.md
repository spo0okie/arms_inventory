# Документация для разработчиков

Документация внутренних механизмов приложения — для тех, кто дорабатывает
ARMS. Не выводится в интерфейс (в отличие от [docs/help/](../help/README.md),
которую рендерит приложение).

Сюда переносятся завершённые планы из [`plans/`](../../plans): в `plans/`
остаются только незавершённые работы, а реализованный механизм оформляется
здесь (конвенция — в [standards.md](../../standards.md), раздел «Планы
(plans/) и жизненный цикл документов»).

## Содержание

- [integrations.md](integrations.md) — механизм подключаемых интеграций с
  внешними ИС (панели в карточках, действия, контракт провайдера,
  композиция, двусторонняя привязка Zabbix).
- [network-map.md](network-map.md) — порты коммутаторов и связи устройств:
  опрос через `macsearch` слоем поверх таблицы портов, вердикты и
  предложения (цепочка телефон→ПК), группы портов, имена и геометрия
  экземпляра, стеки; готчи с живых данных.
- [perf-monitoring.md](perf-monitoring.md) — диагностика производительности:
  время обработки в access-логе, журнал медленных запросов
  (SlowRequestLogger), отчёт `yii perf/report`, Zabbix-шаблон; контракты
  форматов логов.
- [themes.md](themes.md) — темы оформления (светлая/тёмная): механизм
  `data-bs-theme`, SCSS-сборка бутстрап-слоя, токены прикладных
  раскрасок, конвенция «новый цвет = токен», готчи.
