# Документация для разработчиков

Документация внутренних механизмов приложения — для тех, кто дорабатывает
ARMS. Не выводится в интерфейс (в отличие от [docs/help/](../help/README.md),
которую рендерит приложение).

Сюда переносятся завершённые планы из [`plans/`](../../plans): в `plans/`
остаются только незавершённые работы, а реализованный механизм оформляется
здесь (конвенция — в [standards.md](../../standards.md), раздел «Планы
(plans/) и жизненный цикл документов»).

## Содержание

- [integrations.md](integrations.md) — механизм подключаемых интеграций с
  внешними ИС (панели в карточках, действия, контракт провайдера,
  композиция, двусторонняя привязка Zabbix).
